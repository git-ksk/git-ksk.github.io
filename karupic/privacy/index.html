かるぴく / KaruPic プライバシーポリシー

最終更新日: 2026年9月19日 / Last updated: September 19, 2026

1. 基本方針

かるぴく（KaruPic、以下「本アプリ」）は、画像を指定したファイル容量以下へ圧縮するためのiPhone / iPad向けユーティリティです。本アプリの画像処理は端末内で行われ、開発者が運営するサーバーへ画像をアップロードしません。

2. 開発者へ送信・収集しない情報

  • アカウント登録情報
  • 画像・サムネイル・画像内容
  • ファイル名、完全なファイルパス、Photosのasset identifier
  • EXIF / GPS等の画像メタデータを診断目的で自動送信する情報
  • 広告識別子、行動追跡データ、広告向けデータ
  • Firebase Analytics / Crashlytics等の第三者テレメトリ

3. 画像と一時ファイルの扱い

圧縮処理は端末内で実行します。処理のために端末内の一時領域へ入力・結果ファイルを作成する場合がありますが、アプリ内の処理・共有・保存に必要な範囲で使用し、不要になった一時データは削除します。元の写真や元ファイルを本アプリが自動で削除・置換することはありません。

新しくJPEGへ変換した結果では、位置情報など不要なプライバシーメタデータを引き継がない方針です。一方、すでに指定容量以下で変更不要となったファイルは元データをそのまま返すため、元ファイルのメタデータも保持されます。

4. Photos / Files / Share Sheet

ユーザーが選択した写真・ファイルを読み込むために、iOS / iPadOSのPhotos Picker、Files、Share Sheet等のシステム機能を利用します。写真ライブラリへの保存は、ユーザーが明示的に保存操作を行った場合にのみ実行します。

ユーザーがShare Sheet等から他のアプリやクラウドサービスを選択した場合、その時点からは選択された送信先のプライバシーポリシーが適用されます。本アプリがユーザーの操作なしに結果画像を外部サービスへ送信することはありません。

5. 購入情報

本アプリはApp Storeを通じて提供されます。決済処理はAppleが行い、開発者がクレジットカード番号等の決済情報を本アプリ経由で取得することはありません。

6. サポートへのお問い合わせ

ユーザーがメールでサポートへ連絡した場合、送信元メールアドレスとユーザーが入力した本文・添付内容を受け取ります。これらは問い合わせ対応のために使用します。本アプリは画像、ファイル名、パス、EXIF / GPS等を問い合わせメールへ自動添付しません。

お問い合わせ: k.lifetime.app+karupic-support@gmail.com

7. Webページのホスティング

このプライバシーポリシーおよびサポートページ自体には、広告・行動分析用スクリプトを埋め込んでいません。ページはGitHub Pagesでホストされており、GitHubがアクセスログ等を取り扱う場合があります。その取り扱いにはGitHubのプライバシーポリシーが適用されます。

8. 変更

本ポリシーは、アプリの機能や法令・プラットフォーム要件の変更に応じて更新する場合があります。重要な変更はこのページで反映します。

KaruPic Privacy Policy

Last updated: September 19, 2026

1. Overview

KaruPic is an iPhone and iPad utility that compresses images to a user-selected file-size ceiling. Image processing is performed on the device. KaruPic does not upload images to a developer-operated server.

2. Data the developer does not collect

  • Account registration data
  • Images, thumbnails, or image content
  • File names, full file paths, or Photos asset identifiers
  • EXIF or GPS metadata for automatic diagnostics
  • Advertising identifiers, behavioral tracking data, or advertising data
  • Third-party telemetry such as Firebase Analytics or Crashlytics

3. Images and temporary files

Compression runs locally on the device. KaruPic may create temporary input and result files in local temporary storage while processing, saving, or sharing. Temporary data is removed when it is no longer needed. KaruPic does not automatically delete or replace the user's original photo or file.

Newly encoded JPEG results are designed not to carry unnecessary privacy metadata such as location data. If a source file is already under the selected size limit and is passed through unchanged, the original file and its metadata are preserved.

4. Photos, Files, and Share Sheet

KaruPic uses system features such as Photos Picker, Files, and Share Sheet to access content the user selects. Saving to the Photos library happens only after an explicit user action.

If the user chooses another app or cloud service from a Share Sheet, that destination's privacy policy applies from that point. KaruPic does not send result images to external services without the user's action.

5. Purchases

KaruPic is distributed through the App Store. Apple handles payment processing. The developer does not receive credit-card details through the app.

6. Support email

If you contact support by email, we receive the sender address and any text or attachments you choose to send. They are used to respond to your request. KaruPic does not automatically attach images, file names, paths, EXIF, or GPS data to support email.

Support: k.lifetime.app+karupic-support@gmail.com

7. Hosting of these web pages

These privacy and support pages do not embed advertising or behavioral analytics scripts. They are hosted by GitHub Pages, and GitHub may process access logs under its own privacy policy.

8. Changes

This policy may be updated when the app, legal requirements, or platform requirements change. Material changes will be reflected on this page.
