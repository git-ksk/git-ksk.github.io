よくある確認事項

  • 元の動画は消えますか？ — いいえ。かるムビは元動画を自動で削除・置換しません。
  • 動画はサーバーへ送られますか？ — 圧縮処理は端末内で行い、開発者サーバーへ動画をアップロードしません。
  • すでに指定容量以下ならどうなりますか？ — MP4 / H.264 / AACまたは無音声 / 対応SDRの条件を満たす場合は、再圧縮せず元ファイルをそのまま結果として扱います。
  • HDR動画は圧縮できますか？ — 初期リリースはSDR動画を対象としており、非対応のHDR / 広色域動画は圧縮前に明示的に拒否します。
  • オフラインで使えますか？ — 動画がすでに端末上で利用可能なら、圧縮処理自体はオフラインで動作します。iCloud等から元動画を取得する必要がある場合は通信が必要になることがあります。

KaruMovie Support

A simple on-device utility for compressing video to a selected file-size ceiling.

  • Approximate source type, such as 4K/60fps or screen recording

Please avoid sending the original video, file name, file path, Photos identifier, or location metadata unless it is necessary. KaruMovie does not automatically attach those items or device diagnostics to support email.

Common questions

  • Does KaruMovie delete the original video? No. It does not automatically delete or replace the source.
  • Is video uploaded to a server? Compression is performed on the device; KaruMovie does not upload video to a developer-operated server.
  • What if the video is already below the target? A compatible MP4 / H.264 / AAC-or-silent / supported-SDR file is passed through unchanged.
  • Does it compress HDR video? The initial release targets SDR video. Unsupported HDR or wide-color input is rejected before compression.
  • Does compression work offline? Compression itself works offline when the source video is already available on the device. Downloading an original from iCloud or another provider may require network access.
