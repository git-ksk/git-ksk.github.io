かるムビ / KaruMovie プライバシーポリシー

最終更新日: 2026年10月7日 / Last updated: October 7, 2026

1. 基本方針

かるムビ（KaruMovie、以下「本アプリ」）は、動画をユーザーが選んだファイル容量以下へ圧縮するためのiPhone / iPad向けユーティリティです。動画処理は端末内で行われ、開発者が運営するサーバーへ動画をアップロードしません。

2. 開発者へ送信・収集しない情報

  • アカウント登録情報
  • 動画、動画内容、プレビュー画像
  • ファイル名、完全なファイルパス、Photosのasset identifier
  • 位置情報等の動画メタデータを診断目的で自動送信する情報
  • 広告識別子、行動追跡データ、広告向けデータ
  • Firebase Analytics / Crashlytics等の第三者テレメトリ

3. 動画と一時ファイルの扱い

圧縮処理は端末内で実行します。処理、保存、共有のために端末内の一時領域へ入力・結果・共有用ファイルを作成する場合があります。アプリが管理する一時ファイルは不要になった時点で削除し、前回起動時に残ったアプリ管理下の一時データも次回起動時に整理します。元の動画や元ファイルを本アプリが自動で削除・置換することはありません。

新しく圧縮した動画では、任意の元メタデータを出力へコピーしません。再生方向の維持に必要な変換情報など、動画表示に必要な情報は出力へ反映します。すでに指定容量以下で、MP4 / H.264 / AACまたは無音声 / 対応SDRという条件を満たす動画は再圧縮せず元ファイルをそのまま結果として扱うため、その場合は元ファイル内のメタデータも保持されます。

4. Photos / Files / Share Sheet

ユーザーが選択した動画を読み込むために、iOS / iPadOSのPhotos PickerおよびFilesを利用します。写真ライブラリへの動画保存は、ユーザーが明示的に保存操作を行った場合にのみ実行します。

ユーザーがShare Sheetから他のアプリやクラウドサービスを選択した場合、その時点からは選択された送信先のプライバシーポリシーが適用されます。本アプリがユーザーの操作なしに結果動画を外部サービスへ送信することはありません。

5. HDR / 広色域動画

初期リリースではSDR動画を対象としています。PQ、HLG、P3広色域、mastering-display metadataを含む非対応動画は圧縮前に明示的に拒否し、対応していない形式を黙って色変換することはありません。

6. 診断情報

本アプリはOS標準のログ機能を使用して、処理種別、ファイル容量、選択上限、成功/失敗種別、安定したエラーコード等の非センシティブな情報を端末内に記録する場合があります。動画、ファイル名、完全なパス/URL、Photos asset identifier、位置情報等の動画メタデータを診断ログへ記録しません。

Firebase、Crashlytics、Analytics、広告SDK、独自telemetry endpointは使用しません。

7. サポートへのお問い合わせ

ユーザーがメールでサポートへ連絡した場合、送信元メールアドレスとユーザーが入力・添付した内容を受け取ります。これらは問い合わせ対応のために使用します。本アプリは端末診断、動画、ファイル名、パス、Photosの識別子等を問い合わせメールへ自動添付しません。

お問い合わせ: k.lifetime.app+karumovie-support@gmail.com

8. Webページのホスティング

このプライバシーポリシーおよびサポートページ自体には、広告・行動分析用スクリプトを埋め込んでいません。ページはGitHub Pagesでホストされており、GitHubがアクセスログ等を取り扱う場合があります。その取り扱いにはGitHubのプライバシーポリシーが適用されます。

9. 変更

本ポリシーは、アプリの機能や法令・プラットフォーム要件の変更に応じて更新する場合があります。重要な変更はこのページで反映します。

KaruMovie Privacy Policy

Last updated: October 7, 2026

1. Overview

KaruMovie is an iPhone and iPad utility that compresses video to a user-selected file-size ceiling. Video processing is performed on the device. KaruMovie does not upload video to a developer-operated server.

2. Data the developer does not collect

  • Account registration data
  • Video, video content, or preview images
  • File names, full file paths, or Photos asset identifiers
  • Location or other video metadata for automatic diagnostics
  • Advertising identifiers, behavioral tracking data, or advertising data
  • Third-party telemetry such as Firebase Analytics or Crashlytics

3. Video and temporary files

Compression runs locally on the device. KaruMovie may create temporary input, result, and share files in app-managed temporary storage while processing. These files are removed when no longer needed, and stale app-owned temporary sessions from a prior launch are cleaned on a later launch. KaruMovie does not automatically delete or replace the user's original video or file.

Newly encoded output does not copy arbitrary source metadata. Rendering-critical information such as orientation is preserved. If an input is already below the selected ceiling and satisfies the compatible MP4 / H.264 / AAC-or-silent / supported-SDR contract, it is passed through unchanged, so metadata already in that file remains unchanged.

4. Photos, Files, and Share Sheet

KaruMovie uses system features such as Photos Picker and Files to access video the user selects. Saving a result to the Photos library happens only after an explicit user action.

If the user chooses another app or cloud service from the Share Sheet, that destination's privacy policy applies from that point. KaruMovie does not send result video to external services without the user's action.

5. HDR and wide-color video

The initial release targets SDR video. Unsupported PQ, HLG, P3 wide-color, or mastering-display metadata is rejected before transcoding rather than silently color-converted.

6. Diagnostics

KaruMovie may use the operating system's logging facilities to record non-sensitive operational information such as processing stage, byte counts, selected target, result type, and stable error codes. It does not log the video, file names, full paths or URLs, Photos asset identifiers, or location/video metadata.

KaruMovie does not use Firebase, Crashlytics, analytics SDKs, advertising SDKs, or a developer telemetry endpoint.

7. Support email

If you contact support by email, we receive the sender address and any text or attachments you choose to send. They are used to respond to your request. KaruMovie does not automatically attach device diagnostics, video, file names, paths, or Photos identifiers to support email.

Support: k.lifetime.app+karumovie-support@gmail.com

8. Hosting of these web pages

These privacy and support pages do not embed advertising or behavioral analytics scripts. They are hosted by GitHub Pages, and GitHub may process access logs under its own privacy policy.

9. Changes

This policy may be updated when the app, legal requirements, or platform requirements change. Material changes will be reflected on this page.
